# 🐱🐶 Cat vs Dog Classifier (Streamlit + Hugging Face API)

A simple image classification web app built using **Streamlit** that predicts whether an uploaded image contains a **Cat** or **Dog**.  
The model is deployed on **Hugging Face Inference API**, and this frontend sends a request to the model endpoint.

---

## 🚀 Features
- Upload images (JPG/JPEG/PNG)
- Sends image request to Hugging Face API
- Displays prediction label and confidence score
- Clean and simple UI with Streamlit

---

## 🧠 Tech Stack
| Component | Technology |
|----------|------------|
| Machine Learning Model | Hugging Face Model Inference API |
| Frontend Framework | Streamlit |
| Image Processing | Pillow |
| API Request | Python `requests` |
